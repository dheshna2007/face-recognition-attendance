# Face Recognition Attendance System

An AI-based face recognition system developed to automate student attendance and reduce the time and effort required for manual attendance marking.

## 📌 Problem

Manual attendance can be time-consuming, especially when dealing with a large number of students. It can also lead to human errors and make attendance records harder to maintain.

This project explores the use of facial recognition to make the attendance process faster and more efficient.

## 💡 Solution

The system captures faces through a webcam and compares them with previously stored training data.

The basic workflow is:

1. Capture the user's face through a webcam.
2. Detect and locate the face in the image.
3. Compare the detected face with the trained faces.
4. Identify the person.
5. Use the identification result to record attendance.

## 🛠️ Technologies Used

- Python
- OpenCV
- dlib
- Visual Studio

## 🧪 Testing

The prototype was tested with selected Class XII students.

During testing, the system achieved approximately 80% recognition success. The model was able to recognize students' faces, but performance could be affected by changes in hairstyle, clothing, and other variations.

### Improvements Identified

- Faster face detection
- More training data
- Higher-quality datasets
- More advanced software and libraries
